# Documentação do Projeto

O **UneTask** é uma aplicação mobile multiplataforma (Web, iOS e Android) para gestão de tarefas acadêmicas, voltada a estudantes do ensino básico ao superior. A solução centraliza a rotina de estudos em uma única plataforma, com cadastro de tarefas categorizadas por matéria, dashboard de acompanhamento e quadro interativo baseado em Scrum/Kanban.

Este diretório reúne a documentação completa do gerenciamento do projeto, organizada nas cinco fases do ciclo de vida. Cada fase contém o documento principal em `README.md`; quando há registros complementares, eles ficam em `artefatos/` dentro da própria fase.

| Item | Informação |
|------|------------|
| Período de execução | 03/08/2026 a 10/09/2026 |
| Esforço | 800 horas |
| Orçamento | R$ 53.050,00 |
| Metodologia | Scrum, com 4 sprints de 1 semana |
| Equipe | 5 integrantes |
| Situação | Encerrado formalmente em 10/09/2026 |

Fases do Gerenciamento do Projeto:
1. [Iniciação](/docs/01-iniciacao) — termo de abertura, partes interessadas e declaração de escopo
2. [Planejamento](/docs/02-planejamento) — EAP, matriz RACI, cronograma, orçamento e planos de gerenciamento
3. [Execução](/docs/03-execucao) — protótipo navegável, arquitetura, diagrama de classes e modelo de dados
4. [Monitoramento](/docs/04-monitoramento) — indicadores de desempenho, controle de mudanças, riscos e atas de reunião
5. [Encerramento](/docs/05-encerramento) — termo de encerramento, lições aprendidas e auto-avaliação
